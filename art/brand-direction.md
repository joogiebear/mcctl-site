# SpawnLoft / Own your world

Visual thesis: a precise, dark control room meets a sculptural voxel world, energized by a single electric lime accent.

Content plan: lead with the SpawnLoft world and a clear download action; demonstrate server control through real product screens; explain customization and backups; close with an invitation to start a world.

Interaction thesis: assemble the hero quickly, advance distinct world states with short scroll chapters, and give buttons a crisp directional response. A visitor should see meaningful changes immediately. Respect reduced motion and keep mobile interactions direct.

## Identity

- Ink `#090c0d`: dominant background and negative space.
- Bone `#f0eee7`: primary type and calm editorial surfaces.
- Electric lime `#c4f566`: actions, active states, and model lighting.
- Muted text `#b5b8ae`; quiet dividers `#30372c`.

The mark is an original stepped S: two offset rectangular openings connected by a bevel. It echoes voxel construction without borrowing Minecraft's creeper or wordmark. Keep generous clear space and avoid adding outlines, shadows, or a second accent.

The custom icon family uses a 24-unit grid, substantial square strokes, angular silhouettes, and matching cube geometry. GitHub and Windows icons are recognizable service/platform identifiers; the remaining symbols are original geometric drawings.

Voice: short, confident, specific. Speak to people building worlds with friends. Demonstrate existing capabilities with actual interface imagery. Never invent customer counts, performance guarantees, premium pricing, testimonials, or availability. Future subscriptions should be presented only when the offer is defined.

## Assets

- `public/brand/mark.svg`: standalone lime mark on transparency.
- `public/favicon.svg`: mark on ink, suitable for browser tabs.
- `public/brand/social-card.svg`: editable 1200 × 630 share composition; rasterize before using as Open Graph artwork because many social crawlers do not render SVG.
- `.vitepress/theme/BrandIcon.vue`: `name` and optional numeric `size` (24 by default). Inherits `currentColor`; decorative by default. Label the parent control when used alone.
