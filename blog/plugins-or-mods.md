# Plugins or mods? Decide before you build

The first real decision when you create a server is the software, and it is also the one that is hardest to change later. The short version: **plugins** run on Paper and its relatives, **mods** run on Fabric and NeoForge, and one server cannot do both.

## The question that decides it

Ask: *do my friends have to install something to join?*

- **With plugins, no.** Everyone joins with plain Minecraft. The server adds features and rules: homes, claims, shops, minigames.
- **With mods, usually yes.** Mods change the game itself, so players need the same mods on their side, at the same version. A mismatch is the most common reason a friend cannot join a modded server.

If your group is a mix of casual players and you do not want to support a mod installation for anyone, choose Paper.

## When to pick which

| You want | Choose |
| --- | --- |
| A server for friends with plugins and no fuss | Paper |
| The same, with more settings to tune | Purpur |
| Nothing added | Vanilla |
| Mods that change the game | Fabric or NeoForge |
| A ready-made modded world | A modpack, built from Modrinth in one step |

Fabric and NeoForge are not interchangeable: a mod is built for one or the other, so check which your favourite mods support before you choose.

## What changing your mind costs

Paper, Purpur, Folia and Advanced Slime Paper can upgrade in place. Moving *between* kinds of software, say Paper to Fabric, is a new server: create it and bring your world across. That is not impossible, but plugins and mods do not carry over, and anything they stored in the world may not make sense to the other side. Decide first and it never comes up.

## Try before you commit

Create a throwaway server, try it for an evening, and delete it. SpawnLoft usually makes that a few minutes' work, and [try it on a copy](/guide/try-it-safely) is how to do it with a real server.
